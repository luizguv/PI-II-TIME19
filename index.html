Demanda #01 - Desenvolvimento Tela de Login

Classificação: Tarefa
Prioridade: Crítica
Status: Em andamento

Descrição:

Implementar a tela de login responsiva do sistema de demandas utilizando React e Tailwind CSS para o front-end, conectada a uma API Node.js/Express. O componente deve realizar a validação de e-mail e senha no cliente e autenticar o usuário via tokens JWT integrados ao banco PostgreSQL. É necessário exibir mensagens de erro em tempo real para campos inválidos.
