# Sistema De Acompanhamento de Demandas de Desenvolvimento
### PI-II-TIME19

## Componente Curricular
Mobiliza e integra as competências para desenvolvimento de projeto, empregando em
equipe um método de desenvolvimento sistematizado, visando abranger a definição de
requisitos, as bases da programação de sistemas de software na Internet e aplicando
estruturas e bancos de dados.

**2º Semestre de 2026**

## Sobre o Projeto
Sistema de gestão de demandas de desenvolvimento, permitindo organizar, acompanhar
e gerenciar tarefas e problemas de um projeto de software.

## Como Executar
1. Clone o repositório:
   ```
   git clone https://github.com/luizguv/PI-II-TIME19.git
   ```
2. Abra o arquivo `frontend/index.html` diretamente no navegador
   (ou utilize a extensão **Live Server** no VSCode).

## Controle de Versão
O desenvolvimento é realizado em branches individuais por feature/tela,
integradas à branch `main` por meio de Pull Requests (PR). A organização de tarefas e
apontamento de horas é realizado no GitHub Projects do repositório.
