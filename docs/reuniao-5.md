# Checklist de integração — Reunião 5

Esta lista descreve o trabalho implementado nesta branch. Não comprova execução
individual dos outros integrantes nem substitui os cards do GitHub Projects.

- Login Oracle, erros 400/401, cookie HttpOnly, sessão persistida e logout.
- Dashboard, listagem, cadastro/edição e detalhes consumindo API e Oracle.
- Projetos/responsáveis dinâmicos, comentários persistentes e histórico.
- Transições de status, cancelamento lógico, permissões e feriados externos.
- Script de tabelas, carga inicial de três perfis, README e testes.

Antes da banca, o grupo precisa:

- Confirmar a matriz de permissões com o Documento de Visão (item 2.1).
- Confirmar quem assume cada tela; os arquivos antigos de cadastro também trazem Vinicius como autor.
- Abrir/atualizar os cards de cada atividade no GitHub Projects e informar os responsáveis efetivos.
- Registrar estimativa e tempo realmente gasto por cada integrante, sem retroagir valores fictícios.
- Demonstrar cada tela com operação válida e erro visível, e explicar a contribuição individual.
- Revisar a branch, integrar por PR e criar/publicar `1.0.0-final` somente na versão entregue.
- Conferir datas e presença de todos no Canvas; a documentação enviada não contém o cronograma.
